# ETTm1 - Oil temperature forecasting (CNN / LSTM)

Task: predict OT (transformer oil temperature) 24h ahead (96 steps) from the previous 24h (96 steps) of 7 variables.
Split by time: 12 / 4 / 4 months (train / val / test). Scaler fitted on train only.

## Dataset and split

ETTm1 is a real-world multivariate time-series dataset collected from an electricity transformer. It contains six load-related variables and oil temperature (`OT`) at 15-minute intervals. The fixed split follows the common ETT protocol using 30-day blocks: 12 months for training, 4 for validation, and 4 for testing. The scaler is fitted on training data only, preventing future-data leakage.

The ARFF file contains 69,680 rows. This implementation deliberately uses the first 57,600 rows required by the fixed 12/4/4 split. The remaining rows are not silently treated as test data because that would change the predefined protocol.

## Why CNN and LSTM

- LSTM models long-range temporal dependencies and repeated operating patterns.
- 1D-CNN extracts short local changes and motifs efficiently.
- CNN-LSTM first extracts local features and then models their temporal order.

Traditional comparisons include Ridge, Random Forest, and XGBoost. A persistence-based Naive predictor is also included because it is a strong reference for a slowly changing time series.

## Evaluation protocol

Model and improvement selection uses **validation RMSE only**. Candidate improvements do not predict the test set. After the best improvement is frozen, it is retrained and evaluated on the test set once. Test MAE, RMSE, and R² are reported over three seeds for deep-learning models.

Tables report `mean ± standard deviation` across seeds. Detailed DL prediction and error plots use seed 0 and are labelled accordingly, so a seed-0 curve is not presented as an averaged prediction.

The current results show that the Naive baseline outperforms the deep-learning models. This is a valid experimental result: the train/test oil-temperature distributions differ substantially. The report should discuss this temporal distribution shift and the resulting generalization limitation. The residual-target experiment improves CNN-LSTM, but it does not outperform persistence.

## Run
```
pip install -r requirements.txt
python run_all.py          # full run (3 seeds, up to 40 epochs)
python run_all.py --fast   # quick smoke test
```
TensorFlow 2.16 or newer is required when using Python 3.12.
Or one step at a time: `01_eda.py`, `02_ml_baselines.py`, `03_deep_learning.py`, `04_improvements.py`, `05_analysis.py`.
